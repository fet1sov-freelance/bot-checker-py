# БОТ Отслеживания онлайн статуса
Бот написанный на для отслеживание статуса онлайна пользователей прописанных в файле **radarids.txt**.
Бот проверяет статус пользователей из списка раз в минуту, при том добавляя историю в базу данных **radar.db**, после проверки, добавляется строка с указанием даты, имени пользователя и статуса по указанным кодом:
1 - онлайн
0 - оффлайн
2 - менее минуты назад

![image](https://github.com/user-attachments/assets/501aa20e-3967-46a1-adbe-a213ee787f93)

## Инструкция по запуску
**1.** Необходимо распаковать файлы проекта и установить все зависимости:
```
pip install -r requirements.txt
```

**2.** Прописать необходимых пользователей для слежки, а именно имена пользователей

![image](https://github.com/user-attachments/assets/25fe979b-5a05-4ff5-ac76-27abe02a8c65)

**_Имя пользователя можно найти в профиле пользователя_**

**3.** Запустить скрипт:
```
py .
```
